# Landing page — Grupul Vatra, Filiala Torino Nord

Versiunea curentă este **v4.0**. Ea consolidează într-un singur fișier tot conținutul
versiunilor anterioare, fără informații dublate, și adaugă modulul de grafică și efecte.

## Ce se publică

| Fișier | Rol |
|---|---|
| `landing-torino-nord-v4.html` | **pagina de publicat** — se lipește într-un widget HTML în Elementor |
| `GHID_PUBLICARE_v4.md` | instrucțiuni pas cu pas, tabelul cu textele alternative, setările Yoast |
| `schema-torino-nord-v4.json` | datele structurate, incluse deja în pagină; fișierul e doar pentru verificare |
| `PREVIZUALIZARE-TORINO-NORD-v4.html` | previzualizare locală, cu fotografii încorporate — **nu se publică** |
| `grafica-sociala/` | Open Graph, Facebook, Instagram, Story |

## Ce rămâne ca istoric

`landing-torino-nord-v2.html`, `02_LANDING_TORINO_NORD_ELEMENTOR_v1.0.html`,
`PREVIZUALIZARE-local.html`, `PREVIZUALIZARE-TORINO-NORD-v2.html`,
`schema-torino-nord.json` și `schema-torino-nord-v2.json` rămân în depozit ca istoric.
Nu se publică niciunul.

## Reguli respectate în pagină

- nu se publică tarife; prețurile se comunică în privat
- nu se publică regulamente ale asociației, școlii, grupurilor sau ansamblurilor
- fostul angajat nu apare nicăieri
- sigla se așază din fișierul oficial, nu se redesenează
- paleta, tipografia și raportul 70/20/10 din brandbook
- „Namu" apare o singură dată, la sloganul de final
